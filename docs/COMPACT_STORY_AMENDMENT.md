# Compact story exploratory amendment

Authorized scope: two fresh, clear 14-sentence development stories; ten named
participants/objects/places each; three questions per story. Not registered
C1/C2, ontology-construction evidence, or a replacement for any mandatory work.
Original ladder, C0, primary metrics and held-out review requirements are unchanged.

Eight single attempts: both query-blind pre-extractions first, then each story's
possession, interval-location, and belief/reality questions. Same complete evidence
for all requests within a story. The actual pre-extractions are hashed and sealed
before contextual transmission, even if they fail. No retry or adaptive tuning.

Use the unchanged short v2 instructions and unconstrained streaming transport,
pinned Qwen3-8B-AWQ/tokenizer, nonthinking template and sampling. All eight requests
receive the same 2,048-output allowance inside 12,288 total context. A complete
14-record authored fixture with ordinary JSON spacing must fit with at least 25%
capacity margin before launch; that test is not a model result. Request/token
hashes and installed server request validation freeze before allocation.

Reference facts are explicit independent scorer records, never transmitted.
`scorer_only/compact_story.py` freezes target sets: possession S1–4/S13 (five);
locations S5–8 (four); belief and stated reality S9–12 (four). The late S14 interval
is outside the location window. Source intervals are never clipped to a query.
Undated facts omit bounds. Direct narration omits holder/attitude; only explicit
belief uses these fields. No inferred persistence, knowledge or identity merging.

Prospective equivalence: case/whitespace; optional leading "the" for exact named
endpoints; listed owns/carries/located_in synonyms and owned_by/carried_by inverse
relations. No later aliases or inverse rules. Citation lists require distinct
supplied string IDs and exact source support for full matching. Unknown wording
is unresolved, not positive support or automatic falsity. All predictions remain
in one-to-one metric denominators, including duplicates and irrelevant facts.

A filters only actual existing records: direct ownership/carrying categories;
direct locations with increasing explicit bounds overlapping the requested
half-open window; attributed records plus narrated locations of those attributed
subjects. It logs all selected/excluded indices, does not repair, deduplicate,
clip or consult gold. Missing/invalid categories or intervals can cause omission;
this is measured baseline behavior. B generates directly from evidence/question.
All parseable records are displayed independently of achieved accuracy.

One new service start, at most eight requests; baseline 10,070.219657 allocated
seconds, additional cap 900, cumulative cap 10,970.219657. Stage caps: startup 300,
live checks 15, each generation 60 plus 5 exception drain, validation 10, protected
shutdown 60 plus 5 guard. Whole envelope takes precedence; no next call without
its full watchdog, bookkeeping and shutdown reserve. The explicit exploratory
complete-forecast exception does not admit ordinary study work. Global scheduled
33,660 and strict actual <36,000 seconds, storage and memory limits remain.

Reuse the existing controller/guardian/client/sampler and reporting path. Safe
resource or transport failure can stop the batch; semantic failure alone cannot.
Keep all raw responses, incomplete cases, failure evidence and previous accounting.
